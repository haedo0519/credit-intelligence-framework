# CIF 프로젝트 요약 (면접·포트폴리오용)

## 한 줄 소개
재무제표를 검증·분석하고, **코드가 계산한 수치만 근거로** AI가 여신심사 검토 보고서를 쓰게 한 뒤, AI 문장을 다시 코드로 검증하는 개인 PC용 분석 도구.

## 해결하려던 문제
LLM에 재무제표를 주고 "심사 의견을 써 줘"라고 하면 그럴듯하지만 **수치를 틀리거나, 근거 없는 주장을 하거나, 승인·거절을 단정**할 수 있다.
금융 업무에서는 "누가 어떤 근거로 이 숫자를 썼는가"를 설명할 수 있어야 한다.

## 접근 방식
| 결정 | 이유 |
|---|---|
| 계산(Python)과 해석(AI)을 분리 | 수치는 재현·검증 가능해야 함. AI는 계산하지 않고 해석만 |
| AI에게 ID가 붙은 근거 패키지만 전달 | 모든 문장이 어떤 수치에 기댔는지 추적 가능 |
| AI 문장을 코드로 재검증 | 본문 숫자가 인용 근거(또는 그 차이·증감률)와 맞지 않으면 "수치 불일치"로 분리, 사실로 쓰지 않음 |
| 스키마에 승인·거절 필드 없음 + 결정 표현 차단 | 도구가 대출 결정을 내리지 않도록 구조적으로 막음 |
| 기준값은 YAML 설정, 해시 기록 | 업종·정책마다 다른 기준을 코드 수정 없이 바꾸고, 어떤 기준으로 분석했는지 남김 |
| 분석 이력 추가만 허용(DB 트리거) | 과거 판단 근거를 사후에 바꿀 수 없게 |
| "판단 불가"를 별도 상태로 | 자료가 없을 때 "위험 없음"으로 오인하지 않게 |
| AI 실패 시 규칙 기반 문장으로 대체 | 외부 API에 의존하지 않고 항상 결과 제공 |

## 규모
재무비율 10종 · 위험 규칙 7종 · 스트레스 시나리오 5종(+사용자 정의) · 보고서 10개 섹션과 차트 4종 · Streamlit 화면 8개 · 자동 테스트 248개

## 개발 중 실제로 발견하고 고친 문제
테스트와 실제 실행으로 찾은 것만 적었다.
1. **재고자산 누락이 검증 화면에서 안 보임**: 당좌비율에 쓰이는 계정이 필수 목록에서 빠져 있었음 (테스트가 발견) → 비율에 쓰이는 계정 전부를 필수로.
2. **영업손실 기업의 매출 감소 시나리오가 손실 축소로 계산**: 이익률 고정 가정 = 비용 전부 변동비라는 숨은 가정 → 고정비 비중을 설정값으로 분리하고, 0일 때 경고 표시.
3. **API 키가 없을 때 앱이 멈춤**: SDK가 예상과 다른 종류의 오류를 던짐 (실제 실행에서 발견) → 인증 오류만 처리하고 다른 코드 버그는 숨기지 않게.
4. **검증기 오탐**: "2024~2025년"의 2024를 금액으로 읽음 (실제 Claude 응답에서 발견) → 연도 범위 처리.
5. **AI가 시연 데이터의 결함을 지적**: 자본 감소폭과 순손실이 맞지 않음 → 데이터 생성기 수정, 자본 = 전기 자본 + 순이익 테스트 추가.
6. **PDF 한글이 네모로 출력**: PDF 라이브러리의 보안 정책이 글꼴 폴더 접근을 막음 → 보안 정책은 유지하고 글꼴 폴더만 허용 (AI 문장이 들어가는 문서라 네트워크·파일 접근을 열지 않음).
7. **새 환경 설치 시 테스트 오류**: 선택 설치 패키지가 없으면 테스트가 실패 (깨끗한 폴더 설치 점검에서 발견) → 해당 테스트는 건너뛰도록.

## 실제 AI 결과
Claude API(`claude-opus-5-5`)로 한 기업 보고서를 생성: 45문장 중 44문장 근거 검증 통과, 결정 표현 0건.
걸러진 1문장은 숫자 자체는 맞았지만 그 연도의 근거를 인용하지 않은 경우였다 → 검증기가 "맞는 숫자"가 아니라 "출처가 있는 숫자"를 요구한다는 것을 보여 준 사례.

## 예상 질문과 답변 요지
- **왜 AI가 직접 비율을 계산하지 않나?** 계산은 결정적이고 테스트 가능해야 한다. AI 계산은 재현이 안 되고 틀려도 알기 어렵다.
- **AI 문장이 틀리면?** 수치 불일치·근거 없음은 별도 목록으로 분리되고 보고서 본문에 사실로 실리지 않는다. 검증 결과 개수는 보고서 마지막 섹션에 기록된다.
- **같은 자료로 다시 분석하면 결과가 같나?** 수치·위험 신호·스트레스 결과는 같다 (테스트로 확인). AI 문장은 달라질 수 있어 모델명·프롬프트 버전을 함께 기록한다.
- **실무에 바로 쓸 수 있나?** 아니다. 포트폴리오용이며 검증된 신용평가 모델이 아니다. 기준값이 업종 무관 가정이고 외부 정보가 없다.
